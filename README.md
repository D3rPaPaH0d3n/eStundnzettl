## 🚀 Was die App kann

* **Intelligenter Schutz:** Verhindert überlappende Zeiteinträge automatisch.
* **Präzise Erfassung:** Arbeitszeit, Fahrzeit, Urlaub, Krankenstand und Zeitausgleich einfach per Touch eintragen.
* **Anpassbare Tätigkeiten:** Eigene Codes erstellen oder Branchen-Presets übernehmen.
* **Ehrlicher Saldo:** Gleitzeit wird in Echtzeit berechnet – sauber und nachvollziehbar.
* **PDF-Profi:** Monatsübersichten oder einzelne Kalenderwochen als ordentliches Dokument exportieren.
* **Flexible Arbeitsmodelle:** 38,5h, 40h, 4-Tage-Woche oder komplett individuell.

## 📱 Schnellstart

### 1. Erster Start
Die App führt dich gemütlich durch den **Einrichtungs-Assistenten**:
* Name und Firma eintragen
* Arbeitszeitmodell wählen
* Backup-Einstellungen festlegen

### 2. Stunden eintragen
Drück unten rechts auf das **Plus (+)** oder nutz direkt die **Live-Stempeluhr**.

* **Normale Arbeit:** Zeiten einstellen, Tätigkeit wählen, speichern, fertig.
* **🪄 Wie zuletzt:** Übernimmt die Daten vom letzten Eintrag fast von allein.
* **Urlaub / Krank / ZA:** Ein Tap genügt – die Sollzeit wird automatisch berücksichtigt.

### 3. Tätigkeitscodes anpassen
Unter **Einstellungen → Codes verwalten** kannst du:
* eigene Tätigkeiten hinzufügen
* ein Preset für deine Branche laden
* bestehende Codes bearbeiten oder löschen

### 4. Bericht senden 📧
1. Auf der Startseite oben rechts auf das **Dokumenten-Symbol** tippen.
2. Monat oder Kalenderwoche auswählen.
3. **PDF** erstellen und direkt weitergeben.

### 5. Backup einrichten ☁️
Unter **Einstellungen → Backup** kannst du wählen, wie du deine Daten sichern willst:
* lokal in einen Ordner auf deinem Gerät
* mit **Google Drive**
* oder mit **Nextcloud**

## 📲 Installation

<details>
<summary><b>Android (APK)</b></summary>

**Schritt 1: Herunterladen**  
Klick oben auf den grünen Button **„Android App – APK herunterladen“**.

**Schritt 2: Installieren**
1. Öffne die heruntergeladene Datei (meist im Ordner „Downloads“).
2. Falls eine Warnung kommt: Geh auf **Einstellungen** und erlaube **„Unbekannte Apps installieren“**.
3. Tippe auf **Installieren**.

**Fertig!** 🎉

</details>
