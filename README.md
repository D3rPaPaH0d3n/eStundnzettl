## 🚀 Was die App kann

* **Intelligenter Schutz:** Verhindert überlappende Zeiteinträge automatisch.
* **Präzise Erfassung:** Arbeitszeit, Fahrzeit, Urlaub, Krankenstand und Zeitausgleich einfach per Touch.
* **Anpassbare Tätigkeiten:** Erstelle eigene Codes oder nutze vorgefertigte Presets für deine Branche.
* **Ehrlicher Saldo:** Gleitzeit wird in Echtzeit berechnet – nur für vergangene Tage.
* **PDF-Profi:** Stundenzettel im professionellen Design, Monatsübersicht oder einzelne Kalenderwochen.
* **Flexible Arbeitsmodelle:** 38,5h, 40h, 4-Tage-Woche oder komplett individuell.

## 📖 Schnellstart

### 1. Erster Start
Die App führt dich durch einen **Einrichtungs-Assistenten**:
* Name & Firma eintragen
* Arbeitszeitmodell wählen
* Backup-Einstellungen festlegen

### 2. Stunden eintragen
Drücke unten rechts auf das **Plus (+)** oder nutze die **Live-Stempeluhr**.

* **Normale Arbeit:** Zeiten einstellen, Tätigkeit wählen, fertig.
* **🪄 "Wie zuletzt":** Übernimmt sofort alle Daten vom letzten Eintrag.
* **Urlaub / Krank / ZA:** Ein Tap genügt – Sollzeit wird automatisch gutgeschrieben.

### 3. Tätigkeitscodes anpassen
Unter **Einstellungen → Codes verwalten**:
* Eigene Tätigkeiten hinzufügen
* Preset für deine Branche laden
* Bestehende Codes bearbeiten oder löschen

### 4. Bericht senden 📧
1. Auf der Startseite oben rechts auf das **Dokumenten-Symbol** tippen.
2. Monat oder Kalenderwoche auswählen.
3. **PDF** erstellen und per E-Mail versenden.

### 5. Updates erhalten 🔄
**Einstellungen → "Auf Updates prüfen"** – die App lädt neue Versionen direkt herunter.

## 📲 Installation

<details>
<summary><b>Android (APK)</b></summary>

**Schritt 1: Herunterladen**  
Klicke oben auf den grünen Button **"Android App - APK herunterladen"**.

**Schritt 2: Installieren**
1. Öffne die heruntergeladene Datei (meist im Ordner "Downloads").
2. Falls eine Warnung kommt: Klicke auf **Einstellungen** und erlaube **"Unbekannte Apps installieren"**.
3. Klicke auf **Installieren**.

**Fertig!** 🎉

</details>
